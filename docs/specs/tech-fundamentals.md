# Tech Fundamentals

This project is a personal to-do / organizer application. It will be a single-page, modern web application, written with ReactJS on the front end and NodeJS on the back end. It will make user of a PostgreSQL database, and Prisma as an ORM.

The user interface will use Tailwind for look and feel / styling.

The project should be configured for unit testing using Jest.

There will be features that require downloading data into Excel .xlsx format, as well as downloading formatted pages as PDF files, so we'll need libraries for those.
